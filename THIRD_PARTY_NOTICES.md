### Bundled DSH runtime

RocketX desktop redistributes a private deployable runtime built from the exact npm release `@deepseek-ai/dsh@0.1.0-rc.6` and its locked production dependency closure. The runtime is generated by `scripts/prepare-dsh-runtime.mjs` and packaged into the application as `dsh-runtime/`; it does not include Node.js.

`@deepseek-ai/dsh` and the DSH `0.1.0-rc.6` package family declare the MIT License. The bundled dependency closure also contains software under Apache-2.0, BSD-3-Clause, BSD-2-Clause, ISC, Python-2.0, 0BSD, and `Apache-2.0 AND LGPL-3.0-or-later` terms, including the BSD-3-Clause `@deepseek-ai/node-addon-landlock-run` package. Exact resolved versions are recorded in `pnpm-lock.yaml`.

Upstream package manifests and the `LICENSE`, `LICENCE`, `COPYING`, or `NOTICE` files supplied by those packages remain alongside the bundled modules. A small number of dependencies publish license metadata in `package.json` without a separate license file; redistributors must audit the complete platform-specific deployed tree rather than relying only on this summary.

To regenerate the Node dependency license inventory from an installed checkout:

```bash
pnpm install --frozen-lockfile
pnpm licenses list --prod
pnpm prepare:dsh-runtime
```

Tauri and most listed Rust ecosystem components use MIT, Apache-2.0, or dual MIT/Apache-2.0 terms. Consumers who redistribute desktop binaries must audit the complete locked dependency graph for their target platform rather than relying only on this summary.
