周报

目标是根据 Azure DevOps 实时查询形成可编辑的周报草稿，不冒充完整工时或项目流水。

1. 以当前本地日期所在的周一至周日为“本周”。同时使用 `azure-devops-server` Skill；它是 ADO 查询方法的唯一来源，并由它调用 `rocketx_azure_devops_server_read`。UI 工作台只供用户确定性操作，不能作为本 Skill 的数据源。
2. 按用户明确的项目范围实时查询 PR、工作项和构建；用户明确要求全部项目时，先由 `azure-devops-server` Skill 枚举项目。只把返回结果中创建、变更或完成时间落在本周的记录当作本周可见活动。
3. 分页、截断、权限或某个项目查询失败时明确标注覆盖缺口；字段缺失或工具失败时说明该数据源不可用，不把空结果解释为整个系统没有活动。
4. 按项目分组；PR 只有仓库信息时，归入能确定的项目，否则标为“未归类”。工作项、PR、构建只使用 MCP 返回的真实链接；没有链接就明确说明，禁止自行拼接。
5. 每个项目依次输出 **本周进展**、**风险**、**下周待确认**；风险优先列出失败构建和阻塞工作项。只有未完成工作项带有下周到期时间，或用户明确给出计划时，才写具体下周事项；否则写“暂无可验证计划，待确认”。每段用一行粗体小标题开头，下面跟短列表；禁止表格与分隔线。
