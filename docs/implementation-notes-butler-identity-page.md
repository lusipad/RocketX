# Implementation notes — 管家身份统一与专属页面

Plan: 当前对话中的“单一身份来源 + 我的管家页面”方案。

## Summary

已完成可见名称统一、单一身份档案、“我的管家”专属页面、运行指令联动和
亮色/暗色/窄屏适配。原有 Profile、Memory、Skill 与审计仍由既有模块负责，
身份层只描述“它是谁、如何与你相处”，没有复制业务状态或扩大权限。

身份页视觉已从独立的“个人资料卡”收回到 Butler 既有纸面工作台语言：身份摘要、
输入、头像和性格选项都使用平面分隔与紧凑层级，不再使用大横幅和卡片堆叠。

## Decisions

- 默认可见名称使用“管家”；`Butler` 只保留为内部代码命名和兼容键。
- 复用现有 `memory` 工作视图，将“记忆与偏好”升级为“我的管家”，不新增重复导航层级。
- 身份设定使用结构化字段，并作为运行指令的一部分；头像采用本地预设，不引入上传、远端存储或新依赖。
- 现有 Profile、Memory、Skill 和审计能力继续作为专属页面的下半部分。

## Reference semantics

- Keep：单一助手身份、长期上下文、记忆透明可撤销。
- Adapt：把原有技术化“记忆与偏好”页面改为面向关系的个人主页。
- Drop：多 Agent 身份、角色市场和不可解释的人格推断。

## Deviations

- 无。

## Surprises

- `apps/web/src/components/AiSettings.tsx` 原有一套四轴“管家性格”，只写独立
  `localStorage`，没有进入任何运行指令。为避免两个相互矛盾的性格来源，删除该
  平行配置及其孤立模块，将底层 `persona` 编辑入口改名为“高级行为指令”。
- 初版身份页虽然单页视觉质量达标，但大渐变横幅、超大头像和成组圆角卡片脱离了
  Butler 其他页面的“每日纸面”语言。按现有工作台页面重新对照后，保留信息架构，
  仅将表现层改为紧凑标题、线性表单和行式选择器。
- 平面化后仍把身份、概况、Profile、工作分析、重复模式、记忆、Skill 和审计同时
  展开，且暗色主题里大量小字使用 `ink-3`。第二轮删除重复概况，把非日常设置合并
  为默认收起的“管家档案”，并只在该页面把辅助文字提升到 `ink-2`。
- 单一“管家档案”折叠又过度隐藏了能力边界，且页面仍存在 11/12/13px 混用。第三轮
  先将档案改成四页签并明确字号梯度；视觉检查发现页签仍被长表单压在首屏以下。
  最终把“相处设定”与“了解你 / 分析与改进 / 记忆与技能 / 最近动作”提升为身份摘要
  下的五个同级页签，每次只展示一个面板。
- “会的本事”使用横向分隔线清单时，长列表感明显且说明被截断。按用户指定改为
  桌面两列、窄屏单列的低装饰卡片；每张卡完整展示技能名、说明和内置/卸载状态，
  不增加详情页、阴影或新的技能字段。
