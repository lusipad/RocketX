# Implementation notes — 管家单页整体重构

> 文档状态：**历史实施记录**。对应的“一张纸”产品方案已经废弃，本文的截图得分和“已完成”只证明当时切片；当前行为见[管家任务](specs/butler-tasks.md)。

Plan: [butler-page-design.md](./butler-page-design.md)

## Summary

已完成首轮实现。主页面已收敛为单一 ButlerPage；完整对话与管理层互斥显示，关闭不重置会话。历史 rounds 快照、日历索引和房间来源过滤已经接入。第三轮本地视觉 dogfooding 得分 93/100，Web 生产构建和仓库全量回归均通过。

## Decisions

- `2026-07-26`：把“完整对话”和“管家管理”实现为 ButlerPage 内互斥的折叠区域，不新增路由或一级导航。依据：用户要求可以一页化，使用折叠、小图标、轻动画和小按钮快速处理。
- `2026-07-26`：快捷动作采用 14–16px 图标；审批等高风险动作同时保留短文字，避免纯图标歧义。
- `2026-07-26`：收起完整对话只关闭 UI 深度，不重置 `paperRounds`、临时问答范围或底层会话。
- `2026-07-27`：完整对话改为用户居右、管家居左的双侧气泡；复用 RocketX 现有消息语义色，不增加头像或第二套对话状态。
- `2026-07-27`：房间管家从固定右栏改为消息区右下角浮动入口与房间内覆盖层；继续复用 `rightPanel.kind='butler'` 和原房间投影，不收窄分组/会话列表，也不覆盖 Composer。
- `2026-07-27`：保留“在办”每项默认收起的既有状态合同；“今天”改为原生 `details` 标题行，默认全部收起并用旋转箭头原位展开，不新增持久化状态。
- `2026-07-27`：修正纸面与输入区的主题层级：页面使用 `surface-3`，唯一输入容器使用 `surface-4` + `line`，默认态只有一层可辨边界。
- `2026-07-27`：真实 dogfooding 发现左侧有未完成待办但纸面仍显示“没事”；今日纸改为直接投影 `useTodos`，最多显示 5 项并提供行内完成。命中同一待办的 rounds 解释折叠到该行，不再重复占用“今天”。
- `2026-07-27`：每日整理的 `running` / `error` 改为原位轻提示和重试；这两种状态都不再落入空纸。
- `2026-07-26`：历史 rounds 结果按本地日期保存 31 天快照，并按 Rocket.Chat server + account 隔离；日历只作为日期纸面的索引，不新增历史页面。无法安全判定归属的旧无作用域快照不迁移。
- `2026-07-26`：房间浮层从同一 `useButler` / `butlerErrandRuns` 数据按 `rid` 投影，只保留最近一次房间问答。派活草案产生时就冻结房间归属，避免确认前切页导致串房。
- `2026-07-26`：旧会话若没有可靠 `sources`，房间浮层不回退展示全局对话；宁可为空，也不把别的房间内容投影进来。

## Deviations

- 暂时保留隐藏的 Codex runtime 注册，先移除用户路径并验证所有调用方；底层能力不是这轮视觉重构的删除范围。

## Surprises

- `AgentPanel` 仍被 `CreateWorkItemDiscussionDialog` 用作工作项上下文讨论面，它不是要退役的一级“执行间”，因此保留。
- 历史简报原先只有 `rounds-last-result`，翻到更早日期会天然为空；本轮补了按日期快照，而没有新建业务 store。
- 全仓回归暴露了三条绑定旧视觉/旧投影的源码断言；已改为验证快捷提示只填输入框、用户行保留房间来源、房间浮层标题为“房间管家”。

- 真实内容补充验收：本地桌面账号的 1 条逾期待办在纸面可见，截止状态、来源、行内完成和折叠解释均可达；相关 Playwright 2/2、纸面纯回归 6/6、全仓回归 761/761，Web 类型检查与生产构建通过。

## Remaining risks

- 升级前没有 `sources` 的旧对话无法可靠恢复房间归属，因此只在完整对话里可见，不会出现在房间浮层。
- Vite 仍报告既有的大 chunk 和静态/动态混合导入警告；本轮没有引入新依赖，也没有扩大这些构建问题。
