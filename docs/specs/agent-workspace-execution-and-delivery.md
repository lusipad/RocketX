# Agent 工作台：执行、验收与可靠投递

适用：2026-11-15 的 Pi 管家、ACP 执行器及受支持的原生 Codex 交接。产品范围和约束见[重构方案](../rocketx-agent-workspace-refactor-plan.md)，运行结果见[实施记录](../implementation-notes-rocketx-agent-workspace-refactor.md)。本文描述已落地合同，不把模拟服务结果视作生产环境验收。

## 工作与执行身份

- 工作沿用 todo ID。普通待办仍可勾选完成；纳入跟进必须有目标和非空验收条件，`requirementsVersion > 0`。
- 管家用 `create_work_card` 和稳定 requestId 幂等创建工作；工作、来源与创建映射原子保存。问答不调用建卡工具。
- `acp_dispatch_task` 先保存执行动作并返回。执行器、工作目录、要求与成果版本存入动作快照；后台执行不借用当前选中的会话或目录。
- 原生身份包括宿主、来源数据根、账号、运行时和原生 ID。发现日志只说明存在历史；未知活动状态保持只读。
- 原生 Codex 接续需要用户明确确认原端已停止，再消费绑定来源、目录、profile 和账号的短期一次性交接令牌。接续使用原 ID；导入新工作是另一项明确操作。Pi 不接收外部 Codex ID。

## 要求、成果与完成权

- 修改目标、验收和边界会升级要求版本；返工沿原工作 ID 升级成果版本。旧证据保留并标记失效。
- 并发修改通过预期要求／成果版本检查；旧版本执行不能覆盖新要求。编辑中的简报保留输入，冲突显示在原处。
- 通过证据必须覆盖当前版本的各条验收条件。Agent 汇报和一般说明不贡献完成门禁，旧 `humanConfirmedDone` 布尔值也不能绕过。
- `record_work_evidence` 保存模型声明，强制为未通过的 Agent 报告。可信 CI 工具从 ADO 只读核对项目、构建、定义、成功结果和当前提交，再登记构建证据；它只覆盖明确的 CI 条件。
- 人工接受必须由用户明确选择条件，保存当前账号身份和范围。手工验证记录需填写实际结果、来源与覆盖条件。业务完成、执行结束、外部同步与汇报送达分别显示。

## 后台跟进

- 后台服务在内核启动，独立于当前页面。持久事件收件箱、按账号隔离的消息水位和动作幂等键用于恢复。
- 首次历史加载建立观察基线；已有水位的房间在重连时分页补读。补偿未完整完成时不提前跳过中间历史。
- `prepared` 动作可恢复执行；已尝试投递但结果不确定的动作先核对，不能凭“没有看到新水位”判定安全重发。
- 手动和自动派发共用最多两路执行、同目录单写约束。等待前置工作或定时复查时释放执行资源。
- 暂停自动跟进阻止新派发；接管会尝试中断所属当前执行，并保留失败结果；取消后续跟进不等于停止原生外部进程。恢复不清除旧撤销水位。
- 自动轮次、连续失败和截止时间限制继续投入；需要决策、结果未知或验收完成产生变化提醒。无变化不重复通知。
- 应用进程存活时继续跟进。完全退出、休眠和关机期间不承诺执行；下次启动核对持久记录。不能恢复的旧审批明确失效，用户需让执行器重新请求。

## ADO 与汇报出站记录

- 所有外部写入先保存工作及版本、操作者与服务器、目标资源和不可变内容快照。
- ADO 状态更新检查预期 revision 和当前状态，完成后回读；冲突不覆盖，结果未知不自动重新写入。未满足工作验收时不能同步为完成态。
- 汇报按发送上限分段，使用稳定消息 ID，保留逐段回执。重启只核对；明确续投只补缺少的段落。
- 仅对没有历史投递记录、已通过持久 CAS 进入发送状态的首次动作直接发送；回执必须匹配冻结的 ID、讨论室和内容。已有尝试的动作仍先核对；服务器裸 HTTP 400 不能当作不存在消息的证明。真实 Rocket.Chat 8.6.1 已验证正常分段投递与丢回执后的只读恢复，真实 ADO 写入仍需有效登录和明确测试工作项。
- 私人工作、跨讨论室或受众发生变化需要审阅目标与内容；账号或服务器切换后不执行原账号动作。

## 账号与资料

- 原生工作、待办、证据和出站动作使用按账号及服务器隔离的 SQLite 数据库。既有 `butler.db` 首次认领保留 ID，本地免登录数据首次连接时可认领；其他账号使用独立数据库。
- 已入队数据库操作持有原连接，账号切换不把旧结果写入新库。浏览器回退账本随既有账号归档机制隔离。
- 桌面凭据按实际应用标识隔离：正式标识沿用既有 keyring service 名称，其他标识使用独立前缀；作用域未初始化时不回退到正式凭据。测试实例同时使用独立 AppData、WebView profile 和数据库。
- 记忆纠正创建新版本并停用被替代版本，保留来源；过期记录默认不召回。未核验汇报不能自动成为已确认背景。
- 检索覆盖当前账号已缓存的工作、会话、关联资源、成果、简报与文件索引，并说明缓存覆盖和更新时间；不冒充全盘或远端全文检索。
- 已验收工作的成功方法保存在现有 routines 中，默认停用、手动复用。新工作具有独立身份与验收，不复制旧证据或私人记忆。

## 可选能力

S6 已提供[默认关闭的本地 CPU 语音](local-voice.md)：Windows 使用已安装的中文桌面识别器和音库，按住录音、编辑转写、自行发送，手动朗读最新回复；不连接云端语音，不依赖显卡或额外模型下载。网页版和非 Windows 明确提示不可用，文字工作链路继续独立运行。该能力不承诺全双工或 GPT Live 级体验。
