# Agent 工作台输入与工作上下文

> 状态：S1 已实现，已通过回归、浏览器交互与模拟协议验证；真实桌面输入法和原生接续另行验证。
> 基线：2026-11-15 工作树。本规格仅描述本轮输入、工作详情与汇报呈现，不替代旧运行时规格或声明整个重构完成。

## 1 目标与范围

用户在个人管家与执行 Agent 之间切换时，能够保留未发送的要求，并明确当前发送对象。后台结果或失败反馈不会把另一件工作的输入、成果或汇报替换进来。

本轮覆盖管家输入、ACP 输入、右侧工作详情与结构化汇报的进度呈现。原生 Codex 会话的安全接管、完整业务验收和自动同步属于后续切片。

## 2 输入合同

- 中文输入法仍在组合选词时，Enter 不发送；Shift+Enter 保留换行。
- 草稿按账号、运行时、工作目录和会话身份隔离，返回同一目标时恢复相应内容。
- 点击发送时冻结目标；异步连接、附件准备或页面切换不改变该请求的接收方。
- 发送失败保留原请求及其目标，用户可以恢复或重试；不能覆盖后来输入的草稿。
- 重复触发同一个待发送请求不会重复执行；不同目标的草稿与请求状态相互独立。
- 附件跟随所属草稿，页面临时预览引用不能作为可恢复内容的唯一来源。
- 图片尚未读取完成时阻止提前发送，切换会话后的读取结果仍写回原草稿。
- 已提交但结果不明或重启遗留的请求不自动重放，需先核对原会话；明确未提交的失败可直接重试。

文本、已读取图片与失败请求保存在本机当前浏览器或桌面 WebView 的 IndexedDB，按账号作用域隔离，不做云同步。图片独立保存，删除最后一个有效草稿引用后回收。无法持久化时原位提示，页面内输入继续保留。

ACP 仍沿用当前执行器的整轮发送 Promise，同一会话发送期间可填写下一条要求，其他会话可独立发送；本切片不增加原生实时 steer。

## 3 工作详情合同

当前会话关联的工作是默认详情上下文。用户明确选择另一项工作后，后台排序与状态更新不改变该选择。

找不到关联工作或执行会话时，显示相应空状态，不回退到无关对象。当前成果与动态只在所属会话或工作下展示；在工作 B 的详情中不得合入工作 A 的执行结果。

用户选择的工作被删除后，不自动替换为列表中的第一项。用户可以重新选择或返回当前会话。

后台新增成果不自动切换用户正在阅读的标签。用户主动打开成果时切到成果标签，父页面与详情同步这一显式选择。

## 4 汇报进度合同

工作阶段和执行器状态直接描述实际状态。没有可靠分母时不生成阶段百分比，也不把“核验中”换算为 85%。

若执行器提供结构化计划，比例仅表示已完成计划步骤数占全部步骤数；执行中的步骤不算半个完成，计划比例不等于业务验收或工作完成。

汇报生成入口也校验来源归属，不能只依赖前端调用者传对对象。本轮不改变验收门禁和记忆沉淀规则。

## 7 2026-11-16 工作台易用性增量

本节补充已有会话的整理入口与工作卡阅读合同。原生接续、验收和外部投递沿用[执行与可靠投递规格](agent-workspace-execution-and-delivery.md)，不因“加入工作台”获得控制原会话的权限。

### 添加已有会话

- 统一入口为“添加已有会话”，自动发现本机 Codex、Claude Code 等来源；磁盘扫描最多最近 300 个，另含已记录的托管会话。默认最近 7 天，可按来源、项目目录和关键词筛选，明确当前范围及已发现数量。
- 每页 30 个，超过首屏仍可翻页访问。“加入当前范围”覆盖全部筛选结果；勾选后同一个主按钮改为“加入所选”。筛选变化清空选择，翻页保持同一范围的选择。
- 列表展示标题、项目目录、更新时间及记录摘要。“查看对话”才读取最多最近 24 条可读消息，明确只是只读预览；失败可重试，无可读消息不代表原历史为空。
- 添加只建立工作关联，不复制执行器配置、不自动发送、不启动模型或接管外部进程。完整来源身份参与匹配和稳定 requestId，并发和失败重试不重复建卡；账号切换停止旧批次、关闭预览并丢弃迟到结果。
- 批量加入报告新增、已加入和逐项失败，允许只重试失败项。首次加载与扫描有统一状态，完成前禁止批量加入，不把初始空列表显示为无会话；扫描错误保留缓存并说明覆盖未确认。导入页刷新成功也清除工作台的旧扫描警告。

### 卡片与详情

- 新加入工作为普通优先级 3，目标默认使用标题；摘要标为会话摘要，不自动生成交接下一步或验收条件。
- 卡片先说明项目、来源、目标，再展示当前要求／成果版本的最新非失效记录、实际下一步或阻碍。执行者说明仍标未核验；摘要不冒充最新进展，unknown 不冒充正在运行。
- 普通卡不默认附加审批、待验证和暂停提示；存在工作时默认隐藏空阶段，可手动展开。只剩一个非空阶段时，卡片以可读宽度平铺。
- 详情先阅读，编辑目标与下一步、派工、管理阶段和预算折叠。窄窗覆盖整个工作内容区，搜索区不挤低详情；宽屏为 480 px 侧栏。
- 详情保留版本冲突时的输入，迟到保存不得改变另一张卡的编辑基线或错误显示，也不得把提交后的新输入清成已保存；最新失败验证有明确呈现，不能被较旧通过记录遮蔽。跨卡迟到成功／失败、新输入与最新记录已通过定向复现验证。
