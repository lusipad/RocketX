# 可选本地语音

适用：2026-11-15–16 Agent 工作台重构的 S6。该能力使用本机 CPU 和已安装的 Windows 桌面语音组件，为文字工作提供可选输入与朗读。实现与实测结果见[实施记录](../implementation-notes-rocketx-agent-workspace-refactor.md)。

## 入口与平台

- 管家与 ACP 输入区显示“启用本地语音（可选）”。每次启动默认关闭，不持久保存启用状态；关闭时没有麦克风申请、语音能力探测或语音子进程。
- Windows 桌面端启用后检查已安装的中文 `System.Speech` 桌面识别器与 Microsoft Desktop 音库。两种能力分别判断，缺少中文组件时给出提示并允许重新检查，文字输入保持可用。
- 网页版和非 Windows 平台不可用，不自动转到云端、浏览器语音服务或下载模型。没有增加依赖，也不要求显卡。

## 说话与转写

1. 按住“按住说话”，允许麦克风后录音；鼠标／触控与键盘空格、Enter 均可操作。松开结束，最长 30 秒。
2. 录音在本机转为 16 kHz 单声道 PCM16 WAV，再交给 Windows 中文桌面识别器。处理期间显示“正在本机转写”。
3. 成功后将文字追加到发起录音时的输入目标最新草稿，保留转写期间已有的手工修改。用户可编辑，再自行发送；语音不会自动发送、创建工作或调用执行器。
4. 权限拒绝、无设备、空转写、缺少音库或处理失败显示可理解的错误，并允许重试，不清除原草稿。

## 朗读与停止

- 点击“朗读最新回复”才合成并播放；中文音库不可用时禁用。超过 300 字时按钮明确标注“前 300 字”。
- “停止语音”停止当前录音、能力检查、识别、合成或播放，不中断 Agent 工作。
- 关闭、失焦、页面隐藏、切换账号／工作／会话或卸载组件时，撤销该控件的请求，停止麦克风轨道和播放并释放临时音频。迟到的权限授予、转写和朗读结果不能写入新目标。
- 取消按请求 ID 匹配；旧请求的取消不影响后续请求。挂起的能力探测也可取消，允许随后重新启用。原生辅助进程有 35 秒超时和输入／输出上限，结束时回收。

## 本轮验收与边界

| 证据 | 已证明 | 未证明 |
| --- | --- | --- |
| `tests/ui/local-voice.spec.ts` | 默认关闭、可编辑转写不自动发送、账号／目标切换、权限失败、30 秒上限、朗读和挂起探测取消 | 真实硬件权限提示与声学质量；测试使用受控媒体／原生边界 |
| `scripts/regressions/local-voice-audio.test.ts` | 采样转换、WAV 格式和时长边界 | 麦克风或扬声器兼容性 |
| Rust `local_voice` 专项 7／7 | 格式／文本边界、进程超时与输出上限、按 ID 取消、挂起探测恢复、真实 Windows 中文 TTS→ASR | 物理设备拾音／播放、噪声环境或多说话人识别质量 |
| 隔离桌面 `desktop-voice-ipc` 实测 | 真实 Tauri IPC 探测、静默合成→识别；无效 WAV 和空文本返回对应业务错误 | 物理麦克风／扬声器及全双工体验 |

本轮原生专项生成 3990 ms 中文 WAV，再由本机识别器转写；最终桌面真实 IPC 另生成 3520 ms WAV 并识别 12 字中文。两次均未使用麦克风、扬声器或云端语音。当前提供按住说话与手动朗读；不承诺全双工、持续唤醒、自动打断或 GPT Live 级延迟和自然度。
