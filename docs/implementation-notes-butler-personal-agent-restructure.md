# AI 管家个人工作代理改造实施记录

## Decisions

- 保留 `now`、`memory`、`connections` 视图标识以兼容已有入口和运行态，不继续把它们暴露为一级导航。
- 将真正的异步执行称为“委托”，将重复执行称为“定时任务”。
- 全局“今天”复用现有工作台概览，避免再造一套聚合数据模型。

## Deviations

- 原“今日纸”的主动发现没有在本切片全部搬进全局“今天”；它保留为日历与既有入口使用的兼容视图，避免一次改动同时重写主动发现、历史纸和自动整理。

## Surprises

- 旧任务投影同时包含 Butler errand 与 Todo，导致 UI 名称不同但领域对象仍混在一起；本切片已从模型层拆开。
- 原工作台页面本身已经能聚合本地待办和日程，但模块入口被 ADO 配置门禁挡住；去掉门禁即可复用为全局“今天”。

## Questions

- 后续切片是否把“今日纸”的主动发现完全并入全局“今天”，再退役 `now` 兼容视图。

- Web 生产构建通过；仅保留仓库既有的 Vite 动态/静态导入与大 chunk 警告。
- 全量回归测试 937/937 通过。
- 管家工作区 UI 17/17 通过，覆盖宽屏、暗色、窄屏、技能、定时任务与视觉快照。
- 未配置 ADO 的“今天”流程与旧今日纸关键交互通过。
